[00] DESIGN PHILOSOPHY

The portfolio is a precision tool. It does not perform; it operates. Every element is machined to a function. The vintage DSLR metaphor is the only metaphor. There is no idle pulse, no background drone, no narrative voiceover. The mechanism speaks for itself.

A camera is a light-tight box that records truth. The portfolio is a logic-tight system that records capability. Both require correct alignment of elements before the shutter fires.
Negative space is not a design trend. It is the necessary darkness between exposures. Without it, the image (the work) is blown out and unreadable.
The interface is the instrument. The aperture ring rotates. The shutter wipes. The focus brackets confirm. There are no decorative analogies.
Sound is mechanical, not musical. Aperture detents. Shutter curtains. Film advance levers. All audio is opt-in, triggered by user action, and synthesized via raw oscillators.
Accessibility is a technical specification, not a feature. Respect reduced motion. Convey state through weight and opacity, not motion alone.

[02] CAMERA EXPERIENCE LAYER
THE INTERFACE IS THE INSTRUMENT

Every interaction is mapped to a mechanical camera operation. There are no decorative embellishments. The metaphor is complete: if a component cannot be described as a camera function, it is removed.

Aperture Ring (Ambient Progress)
Fixed to the left edge of the viewport (desktop), vertically centered. A 36px SVG assembly of aperture blades. Scroll position drives clockwise rotation via a CSS custom property --aperture-rotation updated through a lightweight scroll listener (no animation library). Aperture opens from f/16 (scroll 0%) to f/1.4 (scroll 100%). Each major section boundary triggers a 20ms detent scale pulse (1.0 → 1.06 → 1.0) via CSS transition, not JS animation. The ring is purely ambient; it has no click targets.

aria-hidden="true". The scroll position is already available via the scrollbar and the content itself.
The Darkroom — Film Negative Reel
Projects live on a horizontal 35mm negative strip in #darkroom. Desktop: vertical scroll scrubs the strip via JS (translate3d). Each frame shows negativeSummary; [ DEVELOP ] opens a positive print modal (brass gate wipe, 180ms). Mobile: horizontal swipe on the strip — no sticky scrub. Legacy #engine redirects here.
Shutter Wipe Transition
A fixed full-screen overlay div sits at z-index: 200, pointer-events: none. Default state: transform: scaleX(0), transform-origin: left. On section change or primary CTA trigger, it receives an .active class that fires a 180ms @keyframes sweep to scaleX(1). A second keyframe handles the re-open. All hardware-accelerated. No clip-path. No blur.
Film Grain (Surface Emulsion)
A single static body::after pseudo-element layers an SVG feTurbulence noise tile across the entire viewport at 3% opacity. pointer-events: none; position: fixed; inset: 0; z-index: 50; (below header 100, modal 500 — see [08] z-index stack). No JavaScript. No re-seed. The grain is the emulsion layer of the screen. On prefers-reduced-motion, the grain remains (it is static) but any other animated textures are disabled.
Exposure Meter (Scroll Depth)
A 2px-wide vertical brass bar fixed adjacent to the aperture ring. Height scales from 0 to 100% proportional to scroll depth. It is a passive analog meter, not an interactive element. Implemented as a single div with transform: scaleY() driven by the same scroll listener as the aperture ring.
Mode Dial (Navigation)
The sticky top navigation is conceptualized as a mode dial: P (Program — Hero), A (Aperture Priority — Engine), M (Manual — Blueprint), and ISO (Contact). Each mode is a text label in mono. The active mode is indicated by a brass underline (1px, 80% width, centered) rather than a background color.
Hot Shoe (Primary CTA)
The main conversion action — [ RELEASE SHUTTER ] — is positioned at the top-center of the hero, analogous to a flash hot shoe. It is a raised brass-bordered button. On engagement, it triggers the shutter wipe and a 200ms mechanical delay before routing to the contact form. The delay models the mechanical shutter curtain deployment.
Audio — Mechanical Only
All sounds are opt-in via a small "SOUND: OFF/ON" toggle in the nav. Uses a lazy-instantiated Web Audio API context. Sounds: aperture detent (20ms, 240Hz transient), shutter curtain (80ms, 90Hz body + 3kHz transient), film advance lever (100ms mechanical ratchet). No ambient loops. No music.

SCROLL SCRUB MATH (DESKTOP)
  • Architecture: JS scroll listener (rAF-throttled) is primary. CSS animation-timeline: scroll() is not used — conflicts with position: sticky.
  • Horizontal: maxTravel = max(0, stripWidth - viewportWidth) — do not name this trackHeight.
  • Vertical track: scrollTrackHeight = maxTravel + innerHeight; scrubRange = scrollTrackHeight - innerHeight.
  • Progress: trackTop = darkroomTrack.getBoundingClientRect().top; progress = clamp(0, 1, (-trackTop) / scrubRange); translateX = -(progress * maxTravel); apply via translate3d.
  • Overflow: strip inside overflow: hidden sticky viewport; no horizontal page scroll. progress === 0 → first frame left; progress === 1 → last frame in view.
  • Resize: ResizeObserver recalculates stripWidth, maxTravel, scrollTrackHeight, scrubRange.
BRASS GATE WIPE (MODAL OPEN — NOT SHUTTER OVERLAY)

Behavior (locked): The modal does not slide in. Overlay + backdrop appear at full size immediately (z-index: 500). Positive print content is mounted beneath the gate at opacity: 0. A .print-wipe layer on top animates a 1px brass bar sweeping left → right via scaleX(0→1) (projector gate), then the gate fades out; content fades in 160ms later. The print is revealed in place — not dragged behind a moving panel.

  • Distinct from Section [02] shutter wipe (section transition). Modal stack: backdrop → content (hidden) → wipe layer (animates once).
  • Line color var(--brass) (#C8A96E); backdrop rgba(6,6,8,0.94); modal root z-index: 500.
  • Direction: brass leading edge sweeps left → right, then wipe layer opacity → 0; content stays open.
  • Timing: wipe 180ms ease-out; content fade-in 120ms starting at 160ms delay.
  • prefers-reduced-motion: skip wipe; content opacity: 1 immediately.

[06] MICRO-INTERACTIONS
EVERY SURFACE HAS A MECHANICAL FUNCTION
Custom Cursor (Reticle)
The default cursor is replaced by a 12px brass ring (SVG), 1px stroke, no fill. Over interactive elements, a crosshair appears (2px horizontal + vertical lines, 6px length, --brass-dim). Over text, the ring collapses to a 2px I-beam. On click, a scale burst (1.0 → 1.3 → 1.0, 120ms). Disabled on touch. Implementation: a single fixed div updated via minimal JS (setting transform: translate() on rAF). No React state binding on mousemove.
Aperture Ring Mechanics
Rotation is driven by a scroll listener that writes to a CSS custom property --scroll-deg on the ring container. The blades are absolutely-positioned divs rotated via transform: rotate(calc(var(--i) * 45deg + var(--scroll-deg))). No SVG path interpolation. No layout. All compositor.
Shutter Release Gate
The primary CTA is a mechanical release. Mousedown triggers the 200ms hold. During this window, the shutter overlay sweeps shut (scaleX). If the user releases early (mouseout), the action aborts and the overlay sweeps open. On successful hold, the route changes. This is the camera's two-stage shutter: half-press to meter, full press to fire.
Mode Dial Selection
Top navigation is a mode dial. Active section is marked by a brass indicator, not a background pill. The indicator is a 1px underline rendered with transform: scaleX(), sliding between nav items via CSS transitions triggered by JS position calculation.
Exposure Meter
A vertical bar adjacent to the aperture ring. Height driven by scroll percentage. Color: --brass at 40% opacity. At section boundaries, the bar briefly flashes full opacity (100ms) — the metering sensor calibrating to new light conditions.
Focus Confirmation
The viewfinder brackets do not appear on all elements. They are reserved for: project cards, the primary CTA, and form inputs. Standard text links receive a simple brass underline. The brackets are a premium state, indicating "this element is in frame and ready to be captured."
ACCESSIBILITY MANDATE: On prefers-reduced-motion: reduce, all animated transforms are disabled. The aperture ring snaps instantly. The shutter wipe is removed (replaced with an instant opacity cross-fade). The custom cursor is hidden. Focus brackets remain as instant state changes. The exposure meter is static. Grain remains (it is not motion).
[07] MOBILE ADAPTATIONS
OPTICAL INSTRUMENTS WORK ON ALL FORMATS
APERTURE RING
The left-edge ring is removed. Replaced by a 4px × 32px vertical progress bar fixed to the bottom edge (centered), growing in height proportional to scroll. No rotation. Minimal battery impact.
VIEWFINDER BRACKETS
Hover state becomes tap-to-toggle. On touch, brackets appear on :active (finger down) and persist for 200ms after release. On keyboard navigation (voiceover, bluetooth keyboard), :focus-visible still triggers brackets.
FILM GRAIN
Remains active. Static overlay has zero performance cost. No changes.
SHUTTER TRANSITION
Horizontal wipe is replaced by a simple vertical slide (transform: translateY) on low-power devices. On devices with prefers-reduced-motion, an instant opacity swap is used.
HERO BOOT
Font scales 62px → 38px Bebas. Boot lines condense to two: metadata + armed status. Grain preserved. Aperture bar appears at bottom.
DARKROOM FILM REEL
No sticky scroll-scrub. .film-reel uses horizontal overflow-x: auto + scroll-snap-type: x mandatory. Frame min(85vw, 320px). Leader tape full-width between prod/lab. Hint: [ swipe → ]. One scroll axis at a time.
CONTACT SHEET
Vertical film strip maintained. Sprocket holes hidden to save horizontal space. DoF recession remains (opacity/weight only). Tap-to-focus works as hover substitute.
SOUND / CURSOR
All audio disabled by default on mobile (no earphones assumption). Toggle hidden. Custom cursor disabled. Native tap highlights removed via -webkit-tap-highlight-color: transparent.
FOLDABLE / 320PX
At 320px (Galaxy Fold cover screen), hero headline drops to 28px. Darkroom film strip uses horizontal swipe. Page padding reduces to 16px. All mechanisms reflow without horizontal scroll.
REDUCED MOTION
If prefers-reduced-motion is active, all transforms and transitions are gutted. The site becomes a static, high-contrast document with brass focus indicators. No exceptions.
