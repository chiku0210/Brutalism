[00] DESIGN PHILOSOPHY

The site operates as a system boot sequence, not a greeting. The visitor doesn't scroll through a portfolio — they initiate one. Every interaction should feel like turning a physical dial or pressing a mechanical key: deliberate, weighted, with consequence.

Order. Logic. Amor Fati. These are not decorative taglines — they are the structural constraints the entire design system is derived from.
No smiling headshots. No "Hi, I'm a developer." The visitor earns the content by initiating the compile sequence.
Negative space is structural, not decorative. Silence between elements carries weight — like the space between notes in Hindustani classical.
Sound is an opt-in layer, not background noise. Muted by default. Activated by the curious. Rewarding to the audiophile.
The system either holds under production load, or it gets rebuilt until it does. This applies to the portfolio itself.

[06] MICRO-DETAILS & INTERACTIONS
THE FEEL OF THE MACHINE
CUSTOM CURSOR
Default: 12×12 brass ring, no fill, 1px stroke in --brass-dim.

On interactive hover: ring fills to --brass solid (120ms).
On click: brief scale burst 1.0 → 1.4 → 1.0 (120ms).
Over text: collapses to 2px I-beam in brass.
On void background: ring strokes down to #2E2E31.

The cursor is the most tactile signal in the entire interface. Every state change should feel deliberate.
PAGE TRANSITIONS
Section nav click: a brass 1px horizontal line sweeps left→right across the full viewport in 180ms, then content fades in. Not a standard opacity fade — closer to a film projector gate wipe.

Scroll-triggered reveals: panels slide up 16px + fade from 0→1 opacity over 300ms (Framer Motion useInView).

Parallax: max 20px vertical shift on hero text layers only.
LEFT-EDGE TICK NAV
Fixed to the left edge of the viewport (desktop only). Four short tick marks — one per section: Hero, Engine, Analog, Blueprint.

Active tick: lit in brass with a slow 2s pulse animation. Inactive ticks: #2E2E31. No labels. No section names. Purely positional — like the mark on an analog dial.
FOOTER
6-cell minimal grid. Left: N/A :: nielless.com in 10px brass mono. Center: build timestamp in #2E2E31. Right: GitHub + LinkedIn as monoline SVG icons in --muted.

IMPLEMENTATION ORDER (RECOMMENDED)
  1. 01
    globals.css — Lock the full token system first. Everything else references it. Don't start any component until this is done.
  2. 02
    AudioEngine.ts — Build and test all five sounds early. They are easy to break late when you're deep in component work.
  3. 03
    CustomCursor.tsx — Install globally in layout.tsx, verify all cursor states work before building any section.
  4. 04
    HeroBoot.tsx — The boot sequence animation is the most complex piece. Do it early while the codebase is clean. The typewriter, staggered reveals, and compile gate all live here.
  5. 05
    SchematicCard.tsx — Most reusable component. Build it once, use it five times. Get the hover states, badge system, and visual slot right here.
  6. 06
    AnalogPanel.tsx + Timeline.tsx — Straightforward once the token system and animation patterns are solid from previous steps.
  7. 07
    Performance pass — Font subsetting (pyftsubset), image optimization, Lighthouse audit, bundle analysis. Target 95+ on all four metrics before ship.

[09] MOBILE CONSIDERATIONS
HERO
Font scales from 62px → 40px Bebas. Left-edge tick nav hides. Terminal boot lines condense to 2 (remove loading line, keep "All systems nominal").
ENGINE
2-column grid → 1-column stack. WCI full-width card stays full-width. Migration arrow diagram reflowed vertically (FROM → (arrow down) → TO).
ANALOG
3-column grid → 1-column stack, panels full-width. Philosophy strip text reduces to 15px.
SOUND
All sounds disabled by default on touch devices. Respect battery context. The sound toggle is still accessible but defaults to off.
CURSOR
Custom brass ring cursor disabled on touch devices. Falls back to native cursor. No custom cursor logic runs.
MOTION
@media (prefers-reduced-motion: reduce) disables all animations — typewriter, staggered reveals, waveform animation, EQ bars, parallax. Static fallback only.
